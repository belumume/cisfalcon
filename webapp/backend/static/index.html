What CisFalcon does

Modern generative models design enhancers meant to be active in one target cell type and silent elsewhere. Many still fire in the wrong cell. Synthesizing and validating one design costs roughly $250–1000 and 2–4 weeks. CisFalcon reads the sequence and predicts the failure first, grounded in a frozen external measured-activity model rather than self-report.

Three layers

  • Gate (deterministic): the frozen atlas DHS64-MPRA activity model, ensembled over independent folds, predicts per-cell activity and the specificity gap. Nothing is trained here.
  • Grounded motif scan: the input sequence is scanned against real JASPAR transcription-factor PWMs, so the diagnosis names driver motifs that are actually present, not guessed.
  • Agent layer (built with Claude): parallel agents interpret the mechanism, ground the risk in the measured benchmark, and adversarially challenge the call; a synthesizer returns the verdict and a motif-level redesign.

The closed loop

When CisFalcon flags a design, it does more than warn. It applies the prescribed motif edit (disrupt the off-target cell's driver motifs, install the target cell's) and re-scores with the same external model. The predicted specificity gap moving in the right direction is an in-silico consistency check on one example, not wet-lab proof the redesign works. What it shows is that the diagnosis names a concrete, mechanistically grounded edit, which a bare score or a single model call narrating a score cannot.

Verified numbers

  • Cross-lab AUROC 0.8013 on 93,435 designs from an independent lab (Gosai/Tewhey 2024), a different design model, and generators the scorer never saw. Zero sequence overlap. Baselines: GC 0.51, random 0.50.
  • Rank by CisFalcon, synthesize the safest half first: specificity failure rate drops from 6.29% to 1.91% (70% fewer failures).
  • How the 0.80 conditions: it is the deployment number for a mixed batch. Remove the cell base-rate and the gate still separates failures at 0.75; remove the cell and generator base-rates at once and the genuine per-sequence signal is 0.66, still well above 0.50. Matched in-distribution (3-cell, out-of-fold) it is 0.896. All reported, never just the highest (cell_prior_baseline.py).
  • Where to trust it (confidence by design regime): a triage ranker, not a hard gate (PPV 0.24 at recall 0.5 at the 6.3% base rate). It is strongest exactly where designs actually fail (Hamiltonian MC generator AUROC 0.92) and near coin-flip on already-well-optimized designs (FastSeqProp 0.62, AdaLead 0.61) that mostly already work. The value of a pre-synthesis falsifier concentrates out-of-distribution, on failure-prone designs and novel cell types, which is where a wrong design costs the most and where the closed loop still names the fix.
